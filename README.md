# MealForge – Menu Planner & Cost Calculator

MealForge is a web application designed for school kitchens, small restaurants, and catering teams. The application helps users plan weekly menus, manage ingredients and recipes, calculate food costs, estimate portion prices, and generate ingredient order lists.

## Motivation

Planning meals for a school canteen or a small restaurant can be challenging. Kitchen staff must consider recipes, ingredient quantities, pricing, and weekly supply needs at the same time. MealForge aims to simplify this process by providing a clear and practical planning tool.

## Main Features

- Manage ingredients with unit prices
- Create recipes from ingredients
- Calculate recipe costs
- Plan a weekly menu
- Set number of portions
- Calculate total menu cost
- Generate ingredient order lists
- Estimate cost per portion
- Save data in browser (LocalStorage)
