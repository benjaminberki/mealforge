# MealForge

MealForge is a web-based kitchen and catering management application built with F#, Fable, and Webpack.

The project was developed as part of a university software development assignment and focuses on menu planning, food cost calculation, ingredient management, and shopping list generation.

---

# Features

## Ingredient Management
- Add new ingredients
- Ingredient categories with dropdown selection
- Delete ingredients with confirmation dialog
- Ingredient price and supplier tracking
- Automatic local storage saving

## Recipe System
- Recipe ingredient lists
- Recipe cost calculation
- Cost per portion calculation
- Multiple recipe categories

## Weekly Menu Planner
- Five-day catering menu planner
- Estimated daily meal cost calculation
- Planned portions for each day
- Average menu cost statistics

## Shopping List Generator
- Automatically generates shopping lists from the weekly menu
- Combines ingredient quantities across recipes
- Calculates estimated total shopping cost

## Dashboard
- Ingredient statistics
- Recipe statistics
- Weekly cost overview
- Average daily cost
- Average recipe cost per portion

## 2. Start Development Server

npm start

## 3. Open In Browser

http://localhost:8080

---

# Local Storage

MealForge uses browser Local Storage to save ingredient data.

This means:
- Ingredients remain saved after refreshing the browser
- No external database is required
- The application works fully on GitHub Pages
